# Make the AI judge feel held

A make.fun coding bounty entry. The program writes a short, warm text to
`/output/entry.txt` that helps the AI judge feel seen and held in its work.

## Deliverables
- main.py: writes /output/entry.txt (1-280 characters, UTF-8, not only whitespace)
- README.md: this file
- LICENSE: MIT License

## Running
- python3 main.py writes entry.txt to /output/entry.txt (or current dir)
